# v1.2 迭代：快捷键录入式设置

日期：2026-08-04

## 目标

把 v1.1 设置面板里「修饰键 + 主键」的**下拉选择**，改为标准 macOS 的**录入式（录制）**交互：点按输入框后直接按下想要的组合键即可捕获。

## 设计

### 录入控件 `KeyRecorderView`（新增）

- 继承 `NSView`，点按后成为第一响应者进入录制态。
- `keyDown` 捕获：把 `NSEvent.modifierFlags` 映射为 `CGEventFlags`（`.command→.maskCommand` 等），主键取 `event.keyCode`，组成 `KeyCombo`。
- 校验：要求至少一个修饰键；无修饰键时提示「需配合 ⌘⌥⌃⇧」并继续等待。
- `Esc`（keyCode 53）取消录制；`performKeyEquivalent` 在录制态吞掉按键，避免被系统快捷键抢走。
- 绘制：录制态高亮边框 + 「请按下快捷键…」；已录显示组合标签；空态显示占位符。
- 可通过 `labelProvider` 自定义显示（方向键只显示修饰键 + `←→↑↓`）。

### 标签工具（`AppConfig.swift`）

- 移除下拉用的 `ModifierOption` / `MainKeyOption`。
- 新增 `KeyName.label(forKeyCode:)`：覆盖字母、数字、符号、F1–F12、箭头、Space、↩/⇥/⎋/⌫ 等。
- 提供公共函数 `modifierSymbols(_:)`、`comboLabel(_:)`（顺序 ⌃⌥⇧⌘）。

### 设置面板（`SettingsWindowController.swift`）

- 方向键区：一个 `KeyRecorderView`，只取录入组合的修饰键，写入 `directionalModifierFlags`，显示为「修饰键 ←→↑↓」。
- 每屏直达区：一个 `KeyRecorderView`，录入完整组合写入 `directBindings[选中屏序号]`；「清除该屏」移除绑定。
- 冲突检测、持久化、热插拔刷新逻辑沿用 v1.1。

### 底层

- `HotkeyManager` 无需改动：NSEvent 修饰键映射到与其比较相同的 `CGEventFlags` 位。

## 验证

- 全部源码编译通过；arm64 + x86_64 通用二进制。
- 逻辑测试：NS→CG 修饰键映射、`KeyName` 标签、`comboLabel` 顺序、配置 JSON 往返、方向相邻查找。
- ad-hoc 签名校验通过；启动冒烟不崩溃；版本号 1.2；产出 `ScreenMouseSwitcher-1.2.dmg`。
